# malashikh-portfolio

Static one-page portfolio for [malashikh.in](https://malashikh.in), built with Astro and designed for Cloudflare Pages.

## Local development

```sh
pnpm install
pnpm dev
```

## Verification

```sh
pnpm check
pnpm build
pnpm preview
```

## Cloudflare Pages

- Production branch: `main`
- Build command: `pnpm build`
- Output directory: `dist`
- Node version: `22`

Attach `malashikh.in` only after the Pages preview has passed visual and functional QA.
